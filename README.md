# tiandao
一个由选择驱动的修仙宗门经营文字策略 Demo。规则引擎管数值，叙事只呈现行为，人性材料学驱动世界演化。
# 天道 · 青悬宗

> 一个穿越者，带着一座破庙里的十几个人，要在南荒活下来、站住脚。
> 三十个回合，每回合三选一。规则引擎管数值，叙事只呈现行为。
> 人性材料学驱动世界演化——你看不到数值，只能从他们的眼神、沉默和选择里猜。

---

## 这是什么

《天道·青悬宗》是一款**回合制文字策略游戏**的早期 Demo。

你是穿越者，醒来在南荒林中，被一个老人收留。老人姓沈，是青玄宗的外门弟子。青玄宗在中州，三十年前被灭。他逃到南方，在荒山上搭了个棚子，取名“青悬宗”——悬望北归，也悬空未定。他临终前给你一把铜钥匙，说：“山门在中州。回得去，就回去。”

但这一局的目标不是北归，是**在南方立足**。

三十个回合，每回合三个选择。宗门能否存续，弟子是去是留，灵脉是枯是旺，全在你一念之间。

---

## 核心特色

- **选择而非操作**：每回合从三个选项中选一个，每个选择都有代价，没有唯一最优解。
- **人性材料学**：弟子有隐藏属性（忠诚、贪婪、勇气、沉默倾向……），你只能从他们的行为、表情和沉默里推测。系统不显示数值，只显示状态标签。
- **行为抽卡**：每回合弟子根据自己的性格自主行动。有人主动请缨，有人私藏灵石，有人一言不发。结果不直接告诉你，只化作叙事里的可观察现象。
- **宗门建设**：藏经阁、炼丹房、练功场、外务堂，升级影响产出与事件成功率。
- **地图与资源**：节点产出、运输成本、归属变化，资源是立足的基础。
- **小说式叙事**：每回合输出 300–600 字的章节，有场景、有人物、有对白、有情绪。
- **终局导出小说**：三十回合结束后，所有章节自动拼接为一部完整的修仙小说，可导出 `.txt` 或 `.html`。

## 当前状态

- 单文件 HTML，无后端，无 LLM，无网络请求
- 三十回合完整流程（一条固定路线）

## 如何游玩

1. 克隆或下载本仓库。
2. 用浏览器打开 `index.html`。
3. 点击“新开一局”，开始你的三十回合。

无需安装任何依赖，无需联网。

---

## 技术细节

- **纯前端**：HTML + CSS + 原生 JavaScript，单文件。
- **存档**：浏览器 `localStorage`，键名 `tiandao_save`。
- **无外部依赖**：不调用任何 API，不使用任何框架。
- **响应式**：手机优先，最大宽度 640px，居中。
